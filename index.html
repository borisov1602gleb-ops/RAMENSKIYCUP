Жеребьёвка команд

Случайно распределяет подтверждённые (боте одобренные) команды по группам — по 4 команды на группу: 4 команды → 1 группа, 8 → 2, 12 → 3, 16 → 4. Нужно минимум 4 команды.

По завершении церемонии группы публикуются на сайт автоматически — для всех посетителей, без чата.

Результаты матчей (группы)

Введите счёт — турнирные таблицы, форма команд и «Ближайшие матчи» на главной пересчитаются автоматически. Пустой счёт = матч не сыгран.

Устроило? Напишите «опубликуй результаты» — закреплю для всех.

Матч-центр: MVP и хронология

Выберите сыгранный матч, укажите MVP и добавьте события (гол/карточка, минута, игрок) — появится в карточке матча на сайте (клик по любому матчу открывает её).

Устроило? Напишите «опубликуй MVP и хронологию» — закреплю для всех.
